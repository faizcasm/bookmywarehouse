# BookMyWarehouse brand assets

A consistent warehouse-and-shipping mark is shared across the customer, partner,
and admin web apps and the Expo mobile app.

## Palette

- Primary blue: `#2563EB`
- Indigo: `#4F46E5`
- Midnight: `#0C1932`
- Mint accent: `#6EE7B7`
- White: `#FFFFFF`

## Files

- Web icons live in each app's `public/icons/` directory.
- Mobile launcher and adaptive icon assets live in `apps/mobile/assets/images/`.

Keep the mark centered with generous clear space. Avoid recoloring the mint accent
or stretching the icon.
